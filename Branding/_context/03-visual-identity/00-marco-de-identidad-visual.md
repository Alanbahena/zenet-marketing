# Marco de identidad visual

> La **doctrina + el índice** de la identidad visual de marca de Zenet (capa marketing). Cualquiera —humano o agente IA— que vaya a diseñar la landing, un post de Zenet o un deck, **carga este doc primero**: aquí está el mapa, los principios, la base provisional y el estado de cada elemento.
>
> **v0.1 base.** Construida sobre el *Zenet Brandbook* (Cloudgaze · Carlo Gutierrez · 2025) **re-anclado a la marca de hoy** + las bases provisionales (2026-06-04). Se afina al diseñar la landing.

## 1. Cómo usar este folder (humano + agente IA)

**Orden de lectura para generar algo on-brand:**
1. **Este `00-marco`** → mapa · principios · base · estado.
2. El doc del elemento que necesites → `01-logo` · `02-color` · `03-tipografia` · `04-iconografia-e-imagen`.
3. **`05-aplicacion-por-superficie`** → cómo se aplica a tu superficie (landing · social · deck).

**Respeta el estado de cada elemento** (clave para no tomar lo provisional como final):

| Marca | Significado |
|---|---|
| ✅ **definido** | Canónico · úsalo tal cual |
| 🟡 **base provisional** | Úsalo como punto de partida · NO como final · se confirma con la landing |
| 🚧 **scaffold** | Aún no definido · **NO inventes** · marca el gap |

**Frontera:** esto es la identidad visual de **marketing** (capa 2). La identidad visual de **producto** (la app · capa 1) vive en `Branding/05-design-system` (se portea del production repo). El visual **personal de Alan** (LinkedIn · capa 3) vive en `Social Media Content Creation/_context/05-sistema-visual-y-generacion-ai.md` — **es de Alan, NO de Zenet**.

## 3. Principios visuales

Derivados de personalidad (`personalidad-y-arquetipo.md` · Sabio + Cuidador), voz (`voz-y-tono.md` · anti-hype) y promesa (`promesa-de-marca.md` · claridad/orden/acompañamiento). Coinciden con la intención del brandbook ("humano/orgánico sobre el frío de un SaaS").

| # | Principio | Qué significa visualmente |
|---|---|---|
| 1 | **Sobrio sobre llamativo** | Base off-white/neutra · acento **contenido** (no flood) · Sabio · anti-hype |
| 2 | **Cálido sobre frío-tech** | Calidez vía acento + glass **cálido** + personas reales · Cuidador · "humano sobre SaaS frío" |
| 3 | **Claro y ordenado** | Mucho aire · jerarquía clara · sin clutter · = la promesa (claridad/orden) |
| 4 | **Sistema sobre decoración** | El motivo apilado comunica **sistema/orden/capas**, no adorno |
| 5 | **Honesto sobre futurista-hueco** | Minimal-futurista sí · pero **sin glow/neón vacío** · sin hype visual |

## 4. Base provisional de marca (las decisiones)

> Fijadas 2026-06-04 como **base de arranque** · 🟡 se confirman/afinan al diseñar la landing (la emoción del color se juzga mejor en la página real).

| Decisión | 🟡 Base provisional | Confirmar con landing |
|---|---|---|
| **Color** | Base **off-white + grises/teal sobrios** · naranja `#FF653B` (existente) como **acento cálido CONTENIDO** · teal secundario | matiz exacto del naranja (¿más terroso/terracota?) · ¿segundo acento? · la emoción real |
| **Futurista** | **Warm-minimal** · glassmorphism **cálido** + off-white + blur suave · limpio pero humano · NO cold-tech-neón | cuánto glass/blur vs. flat por sección |
| **Motivo** | Óvalos apilados reinterpretados: ~~inventario in/out~~ → **"sistema en capas · orden en una red"** · punteado/glass como variaciones | framing narrativo exacto |
| **Imagen** | **DROP food-waste / sostenibilidad** (off-strategy) · mantener **BoH ilustrado + operador real** | estilo exacto de ilustración BoH |

**Frame general:** identidad **práctica · limpia · ordenada · sobria-pero-cálida** · anclada en el brandbook, re-narrada a la marca de hoy.

## 5. Relación con el brandbook (qué se conserva, qué se actualiza)

Fuente: `Branding/Zenet Brandbook.pdf` (Cloudgaze · 2025). Buen craft, pero construido sobre el **posicionamiento viejo** (inventario · reduce desperdicio · paz mental).

| ✅ Se conserva (esencia) | 🔄 Se actualiza (outdated) |
|---|---|
| Isotipo (rocas zen apiladas / Z / eslabones) | Mensajería "smart inventory · reduce el desperdicio · use it or lose it" → al posicionamiento actual |
| Wordmark "zenet" (Geon) | Fotografía de comida podrida / camión de basura → **fuera** (sostenibilidad ya no es pilar) |
| Filosofía Braun / Dieter Rams + "humano sobre frío-tech" | Naranja como protagonista → naranja **contenido** como acento |
| Base off-white + grises/teals sobrios | Significado del motivo: inventario → **sistema/orden** |
| Glassmorphism cálido + patrón punteado/halftone | |

> **Gem:** el motivo de óvalos apilados (diseñado para "inventario") **funciona aún mejor** para el Zenet de hoy: capas apiladas = sistema · orden · "orden en una red". Mismo activo, mejor narrativa.
