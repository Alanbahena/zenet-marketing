# Tipografía

> Cargar `00-marco` primero. Estados: ✅ · 🟡 base · 🚧.

## Familias — 🟡 base

| Rol | Fuente | Uso |
|---|---|---|
| **Primaria** | **Geon** | Títulos y copy · usada en el wordmark · sans serif limpia y amigable · "tecnológica con enfoque humano" |
| **Secundaria** | **Roboto** | Cuerpos de texto · sans serif funcional y legible |

## Principios de uso

- Geon para **impacto** (hero · títulos · frases ancla) · Roboto para **lectura** (párrafos · UI larga).
- Mucho aire · jerarquía clara · sin densidad (principio "claro y ordenado").
- Sin MAYÚSCULAS para énfasis (cf. `reglas-de-redaccion.md`).

## 🚧 / Decisiones abiertas (confirmar con landing)

- **Escala tipográfica** (tamaños · line-height) y **pesos** disponibles de Geon.
- **Fallback web** — Geon es de pago/licencia; definir licencia web o fallback (system sans) para la landing/site.
- Mapeo a tokens de tipo (display / h1-h6 / body / caption).
- Coordinación con el design system de producto (capa 1).
