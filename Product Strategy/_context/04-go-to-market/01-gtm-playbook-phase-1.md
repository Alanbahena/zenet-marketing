## 2. Master strategy frame · phase-based GTM evolution

### 2.1 Core thesis

> **GTM Zenet evolves through 4 master phases (Phase 0 design partners → Phase 1 commercial → Phase 1.5 growth → Phase 2 scaling) · each phase con distinct cohort size · ICP focus · channel mix · team capacity · success criteria. Phase progression by TRIGGER (NOT calendar) · capital constraint SHAPES execution (Path A vs B) · geographic alignment with product phase preserved.**

### 2.2 Phase progression principles canonical

| Principio | Detalle |
|---|---|
| **Phase progression by TRIGGER (NOT calendar)** | Cohort target + validation criteria + bandwidth signals · NOT date-based · disciplina canonical |
| **Capital constraint shapes execution** | Path A vs B GTM scenarios documentados (cf. §3) · capital subfolder owns decision |
| **Geographic alignment with product phase** | TJ Phase 0-1 → BC Phase 1.5 → noroeste Phase 2 → LATAM Phase 5 (Series A trigger) |
| **Cohort mix bias progression Multi-Sitio + Enterprise over time** | Path to profitability requires Multi-Sitio + Enterprise dominance (cf. doc 04 §13.1 hallazgo #2) |
| **Channel mix expands progressively** | Phase 0 founder-direct only · Phase 1.5+ channel scale (La Canasta · consultor partners · CANIRAC institutional) |

### 2.3 Anti-patterns master strategy

| NO hacemos | Razón |
|---|---|
| Phase 1 commercial activation pre-design-partner validation | Disciplina canonical · validation requires Mes 3 GO/NO-GO · cf. doc 02 SF §4.3 |
| Geographic expansion BC pre-Phase 1.5 | Disciplina canonical (`01-industry-and-market/07-geografia.md` v1.0 §16.5) |
| Enterprise tier productization pre-Phase 2 | Sub-segmento C inbound trigger required · NO push pre-validation |
| Channel partnership full activation pre-Phase 1.5 | Product-market fit signals required · La Canasta reputation requires validation |

## 3. Path A vs Path B GTM scenarios · capital integration

### 3.1 Frame canonical

> **Capital structure decision (Path A solo bootstrap vs Path B pre-seed bridge $100-200K USD) OWNED en `05-capital-y-finanzas/00-funding-roadmap.md` (pending) · GTM playbook documenta cómo execution differs under each Path · Path NOT decided aquí.**

### 3.2 Path A · Solo bootstrap GTM execution

**Cuándo aplica:** founder absorbs personal runway (~$300-500K MXN Year 1) + opportunity cost ($24-48K USD foregone foregone income vs MX corporate alternative)

| Dimension | Path A execution |
|---|---|
| **Founder bandwidth** | 60-80 hrs/sem solo · sales motion ceiling ~5 design partners simultáneos |
| **Paid acquisition** | $0 · pure organic LinkedIn + network · disciplina canonical |
| **First hire** | Post-Mes 12 si revenue justifies + fractional admin Mes 0-12 |
| **Channel partner development** | Slow · founder solo time-constrained |
| **Phase 1 commercial GA target** | Q4 2026 / Q1 2027 (slip vs ideal Q3 2026) |
| **Cohort acquisition pace** | 1 design partner/mes Phase 0 · 2-3/mes Phase 1 commercial start |
| **Risk profile** | Single point of failure founder · burnout risk Mes 4-6 · single founder dependency |
| **Pre-seed timing** | Post-Mes 6 si product validation strong O Phase 1.5 forced trigger |

### 3.3 Path B · Pre-seed bridge $100-200K USD GTM execution

**Cuándo aplica:** pre-seed close $100-200K USD post-LOI design partner + product validation signals + pitch ready

| Dimension | Path B execution |
|---|---|
| **Founder bandwidth** | Founder primary + 1-2 fractional helpers (CS junior · admin · part-time eng) |
| **Paid acquisition** | $1-3K USD/mes light pilots (LinkedIn ads · Google ads testing) |
| **First hire** | Junior CS rep Mes 6 ($500-1,250 USD/mes MX salary) |
| **Channel partner development** | Accelerated · founder + helpers split work · CANIRAC parallel |
| **Phase 1 commercial GA target** | Q3 2026 (on-time per ideal) |
| **Cohort acquisition pace** | 2-3 design partners/mes Phase 0 · 5-7/mes Phase 1 commercial start |
| **Risk profile** | Distributed · helpers backup · faster recovery from setbacks |
| **Pre-seed timing** | Pre-Phase 1 launch · 6-12 meses runway secured |

### 3.4 GTM decision criteria · Path A vs Path B activation signals

| Activation criterion | Path A favorable | Path B favorable |
|---|---|---|
| Personal runway available | $300-500K MXN buffer available | Insufficient buffer · pre-seed required |
| Pre-seed pipeline serious | NOT priority · slow | 2+ LOI investor pre-seed conversations active |
| Cohort velocity expectations | Acceptable slip Q4 2026/Q1 2027 GA | Need Q3 2026 GA · investor expectations |
| Team scaling preference | Founder-only Phase 1 · CS hires post-validation | Early team build · risk distribution |
| Founder bandwidth tolerance | High (60-80 hrs/sem sustainable) | Moderate (50-60 hrs/sem preferred) |

### 3.5 Hybrid path consideration

**Hybrid possible:** Friends & Family $50-80K USD bridge + founder bootstrap supplement

- Documentado como option en `05-capital-y-finanzas/00-funding-roadmap.md` (pending)
- GTM execution closer to Path A con marginal helpers
- NOT documented in detail aquí

## 4. Phase progression overview · 4 stages canonical

### 4.1 Master phase progression table

| Phase | Timing hipótesis | Cohort size | ICP focus | Channels active | Team capacity |
|---|---|---|---|---|---|
| **Phase 0** | Q3 2026 - Q1 2027 (3-6 meses) | 5 design partners | Sub-segmento B beachhead · TJ only | Founder direct · network · CANIRAC | Founder solo |
| **Phase 1** | Q1-Q2 2027 (3-6 meses) | 25 commercial | Sub-segmento A + B mix · TJ primary | Founder primary + LinkedIn + referrals + warm intros | Founder + 1-2 hires (Path B) |
| **Phase 1.5** | Q3-Q4 2027 (4-6 meses) | 50 growth | A + B + early C inbound · TJ + selective BC | LinkedIn + La Canasta + consultor partners ramp + paid pilots (Path B) | + Mid CS rep + 1 eng |
| **Phase 2** | Q1 2028+ | 100+ scaling | B + C bias + Enterprise productized · BC + Sonora | Multi-channel + La Canasta scaling + Enterprise sales + paid acquisition active | + CS lead + sales rep + eng team |

### 4.2 Phase transition triggers canonical

| Transition | Trigger criteria (ALL required) |
|---|---|
| **Phase 0 → Phase 1** | (a) 3+ design partners completed Mes 3 GO/NO-GO + (b) sales motion playbook refined v0.2 + (c) commercial readiness checklist complete (Tier 2.0 operational ready · MSA template finalized · pricing PSM-validated directional) |
| **Phase 1 → Phase 1.5** | (a) 15-25 commercial closes + (b) retention ≥80% Mes 3 + (c) NPS ≥30 + (d) channel partner LOI La Canasta o equivalent + (e) Capa 1 P0 prompt caching production stable |
| **Phase 1.5 → Phase 2** | (a) 50+ active customers + (b) Mes 6 cliff atravesado (75%+ retention) + (c) Enterprise tier first close + (d) Capa 1+2 architecture mitigations measured |
| **Phase 2 → Phase 3 (Geographic)** | (a) 100+ customers + (b) BC saturation signals + (c) Series A close O Path A profitability achieved |

### 4.3 Anti-pattern progression

| NO hacemos | Razón |
|---|---|
| Phase progression by calendar | Trigger-based canonical · disciplina post-PMF |
| Phase skipping (Phase 0 → Phase 1.5 direct) | Cohort validation requires phase-by-phase signals |
| Phase regression (downgrading scope post-progression) | Destruye trust · team morale · operational chaos |
| Premature transition (partial criteria met) | All criteria required canonical · NO partial trigger |
