## 2. Frame · capital philosophy

### 2.1 Bootstrap-first bias con pre-seed optionality

> **Empezar bootstrap (Tier 1 NOW · operational readiness) · evaluar pre-seed cuando hay design partner validation (evidence para pitch).** MX cost advantage reduce pre-seed need · preserva optionality.

Razón: bootstrap-first preserva equity + force discipline + valida antes de levantar. Pre-seed optionality permite acelerar si validation llega rápido (Path B) sin comprometer a fundraising prematuro sin evidence.

### 2.2 3 principios canónicos

| Principio | Detalle |
|---|---|
| **Milestone-anchored funding (NOT calendar)** | Cada round desbloqueado por milestone medible · NO date-based · disciplina canonical (cf. geografía §16.5) |
| **MX cost structure como capital efficiency moat** | Pre-seed need $100-200K (vs $150-300K US-inflated) · path to profitability Mes 12-15 · 5-10x cost arbitrage vs US vertical AI (cf. doc 04 §14) |
| **Capital como aceleración NO supervivencia** | Bootstrap viable (MX cost structure) · capital acelera (Path B Q3 2026 GA) · NO rescata modelo roto |

### 2.3 Anti-philosophy

| NO hacemos | Razón |
|---|---|
| Raise antes de validation | Sin evidence · dilución mala · weak pitch |
| Over-raise | Más dilución que necesaria · MX cost reduce need |
| Calendar-based fundraising | Milestone-anchored canonical |
| Premature team scaling pre-revenue | Burn 2-3x · Path A no sostiene |

## 3. Path A vs Path B framework formal

### 3.1 Frame · este doc OWNS la decisión

> Capital structure decision (Path A vs B) **OWNED aquí** · GTM playbook (doc `04-go-to-market/01` §3) **consume** como INPUT para GTM execution scenarios. Resuelve la dependencia abierta del GTM.

### 3.2 Path A · Solo bootstrap

**Definición:** founder absorbe personal runway · NO external capital pre-PMF.

| Dimensión | Detalle |
|---|---|
| Personal runway requirement | ~$300-500K MXN Year 1 (operational overhead + living + buffer) |
| Founder opportunity cost | $24-48K USD foregone (MX corporate role alternative · NO cash · cf. doc 04 §2.6) |
| Founder bandwidth | 60-80 hrs/sem solo · ceiling 5 design partners simultáneos |
| Paid acquisition | $0 · pure organic |
| First hire | Post-Mes 12 si revenue justifies + fractional admin Mes 0-12 |
| Phase 1 GA target | Q4 2026 / Q1 2027 (slip vs ideal Q3 2026) |
| Cohort acquisition pace | 1-2 design partners/mes |
| Break-even hipótesis | Mes 15-18 |
| Risk profile | Single point of failure · burnout Mes 4-6 |

### 3.3 Path B · Pre-seed bridge $100-200K USD

**Definición:** pre-seed close post-LOI design partner + product validation signals.

| Dimensión | Detalle |
|---|---|
| Amount | $100-200K USD (MX cost realistic vs $150-300K US-inflated) |
| Bridge | 12-18 meses runway |
| Founder bandwidth | Founder primary + 1-2 fractional helpers (CS junior · admin · part-time eng) |
| Paid acquisition | $1-3K USD/mes light pilots |
| First hire | Junior CS rep Mes 6 ($500-1,250 USD/mes MX salary) |
| Phase 1 GA target | Q3 2026 (on-time) |
| Cohort acquisition pace | 2-3 design partners/mes |
| Break-even hipótesis | Mes 12-15 |
| Cost | Dilución temprana + 2-3 meses founder time fundraising |

### 3.4 Decision criteria matrix

| Criterion | Path A favorable | Path B favorable |
|---|---|---|
| Personal runway available | $300-500K MXN buffer disponible | Insufficient · pre-seed required |
| Pre-seed pipeline | NOT priority · slow | 2+ LOI investor conversations active |
| Velocity expectations | Acceptable slip Q4/Q1 | Need Q3 2026 GA |
| Risk tolerance | High (founder absorbs · single point) | Distributed preference (helpers backup) |
| Dilution sensitivity | Preserve equity | Accept early dilution for speed |
| Founder bandwidth tolerance | High (60-80 hrs/sem sustainable) | Moderate (50-60 hrs/sem preferred) |

### 3.5 Hybrid path

**Friends & Family $50-80K USD + bootstrap supplement:**
- Bridge parcial menos dilutivo que pre-seed institucional
- GTM execution closer to Path A con marginal helpers
- Permite founder partial draw + small fractional support
- Optionality intermedia

### 3.6 Recommended posture

> **Bootstrap-first · evaluate pre-seed post design partner validation.**

| Stage | Acción |
|---|---|
| NOW (Tier 1) | Bootstrap · operational readiness Tier 1 (~$8K MXN · cf. doc 01) |
| Pre-design-partner (Tier 1.5) | Bootstrap · free preparations · NO pre-seed yet |
| Design partner validation (1-2 LOI + Mes 3 GO/NO-GO) | **Decision point** · evaluate Path A continuation vs Path B pre-seed activation |
| Trigger Path B | Si pre-seed pipeline serious (2+ investor LOI) + velocity needs Q3 GA + personal runway insufficient |
| Trigger Path A continuation | Si personal runway sufficient + acceptable slip + equity preservation priority |

**Razón del bootstrap-first bias:** MX cost advantage hace bootstrap viable (burn menor · break-even Mes 12-15) · validar antes de levantar = pitch más fuerte + menos dilución + optionality preserved.

## 5. Milestone-anchored funding roadmap

### 5.1 Frame · milestone desbloquea round (NOT calendar)

> Cada round se desbloquea por **milestone medible** · NO por fecha. Disciplina canonical (cf. `01-industry-and-market/07-geografia-y-expansion.md` v1.0 §16.5 · pre-condición medible NO calendario).

### 5.2 Milestone → funding mapping

| Milestone | Funding event | Evidence |
|---|---|---|
| 1-2 design partners LOI + intent confirmation | Pre-seed conversation START | Validation signal early |
| Cohort 5 signed + Mes 3 GO/NO-GO + behavioral data | Pre-seed CLOSE | PMF signal early + cost actuals |
| Phase 1 commercial 25 + retención ≥80% + NPS ≥30 | Seed conversation START | PMF validated |
| Phase 1.5 growth 50 + Mes 6 cliff atravesado + Enterprise first close | Seed CLOSE | Scale signal + retention proven |
| Phase 2 scaling 100+ + Enterprise productized + $3-10M ARR | Series A | Scale + economics |
| LATAM Phase 5 readiness | Series A trigger (geographic) | Geographic expansion |

### 5.3 Milestone discipline

- NO raise sin milestone alcanzado (evidence-based fundraising)
- Cada milestone es pre-condición medible (NO calendar date)
- Milestone evidence feeds investor narrative (cf. §8)
- Cross-ref geografía §16.5 (phase progression por pre-condición)
